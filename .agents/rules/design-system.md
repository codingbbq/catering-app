# Enterprise UI Design Rules

All UI changes must follow:
docs/design-system/UI-GUIDELINES.md

## Mandatory Visual Standards

- Executive Monochrome theme.
- Primary: #171717
- Page background: #F5F5F4
- Surface: #FFFFFF
- Border: #E5E5E5
- Main text: #262626
- Secondary text: #737373

## Prohibited Styles

- Pink, purple or bright blue primary colours
- Decorative gradients
- Glassmorphism
- Randomly coloured cards or icons
- Excessive shadows
- Inconsistent border radii
- Unnecessary animations

## Component Standards

- Prefer existing DaisyUI components.
- Use semantic theme tokens.
- Reuse shared components.
- Keep tables, forms and navigation consistent.
- Maintain responsive and accessible layouts.

Never introduce a new visual design language
without explicit user approval.
